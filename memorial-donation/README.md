# 纪念馆捐赠资料管理系统

用于纪念馆登记、审核、展示捐赠资料的全栈系统：工作人员在后台登记捐赠人、物品照片、年代、故事与展示状态；前台展厅只展示「审核通过且已公开」的资料；捐赠人可在线提交更正说明。

## 功能

### 后台（工作人员，需登录）
- **物品登记**：编号、名称、捐赠人、分类、年代、捐赠日期、描述、背后故事、展示状态（库房/展出中/外借/修复中）、公开状态、存放位置
- **图片管理**：多图上传（JPG/PNG/GIF/WebP，≤5MB）、主图设置、排序、删除
- **审核流程**：待审核 → 通过（可同时设为公开）/ 驳回（填写意见，自动转为不公开）
- **更正处理**：查看捐赠人提交的更正说明，采纳或驳回并填写回复
- **分类管理**：自定义分类（文献/实物/影像/口述等），有物品的分类禁止删除
- **捐赠人管理**：登记与维护捐赠人档案，名下有物品的禁止删除
- **数据导出**：物品台账 / 捐赠人名录 / 更正记录，CSV（UTF-8 带 BOM，Excel 可直接打开）
- **账号管理**：管理员可新增工作人员、重置密码；操作日志留痕

### 前台（公众，无需登录）
- 展厅卡片墙：关键词搜索、分类/年代筛选、分页
- 资料详情：图片浏览、物品描述、背后故事、捐赠人、展示状态
- 更正入口：捐赠人针对已公开资料提交更正说明（带 IP 限流）

## 快速开始

```bash
cd memorial-donation
npm run seed    # 初始化默认账号与示例数据（首次）
npm start       # 启动服务，默认 3000 端口
```

- 前台展厅：http://localhost:3000/
- 管理后台：http://localhost:3000/admin/
- 默认账号：`admin` / `admin123`（生产环境请立即修改，并设置 `SESSION_SECRET` 环境变量）

## 技术栈

- Node.js + Express + express-session（登录态）
- sql.js（SQLite WASM，数据持久化于 `data/app.db`，无需原生编译）
- multer（图片上传至 `uploads/`）
- 前端：原生 HTML/CSS/JS，无构建步骤

## 目录结构

```
├── server.js            # 入口
├── src/
│   ├── db.js            # sql.js 封装（查询/事务/防抖落盘）
│   ├── auth.js          # 登录态中间件
│   ├── util.js          # scrypt 密码哈希、CSV 导出
│   ├── seed.js          # 种子数据
│   └── routes/          # auth / public / admin 三组路由
├── public/              # 前台页面 + 后台 SPA
├── data/app.db          # SQLite 数据库文件（运行时生成）
└── uploads/             # 物品图片（运行时生成）
```

## 数据流转

```
登记物品(pending/private) → 审核通过(approved) + 设为公开(public) → 前台可见
                                      ↓
捐赠人提交更正 → 工作人员核实 → 采纳(修改资料)/驳回(附回复)
```

前台 API 强制过滤 `review_status='approved' AND visibility='public'`，未公开资料（含图片列表）不会出现在任何公开接口中。
